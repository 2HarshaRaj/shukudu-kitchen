# v1.17.1 - Dish Type Filters

## Added

- Homepage Dish Type filter UI using existing `relationships.dishTypes` metadata.
- Combined homepage filtering across search, category, meal type, and dish type.
- Dedicated documentation in `docs/DISH_TYPE_FILTERS.md`.

## Fixed

- Added extra spacing between the Meal Type pill row and the Dish Type heading on mobile.

## Notes

The Dish Type filter is injected by `script.js` beside the existing Meal Type filter. This avoided unnecessary homepage markup changes while keeping the feature simple for GitHub Pages.
